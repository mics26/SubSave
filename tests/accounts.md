# Account and subscription verification

Start SubSave using the [README](../README.md). Use two made-up email addresses.

1. Create the first account and confirm the dashboard starts empty. Add a
   subscription, refresh the page, and confirm it still appears.
2. Run the Workbench query from the README and find the saved row in `subsave`.
3. Log out, create a second account, and log in with its credentials. Confirm
   it has zero subscriptions. Log back in as the first account and confirm its
   row still appears.
4. Edit and delete a subscription on its owner's account. Confirm each change
   persists after refresh.
5. Open **Your account** and change the display name. Try changing the email
   or password with an incorrect current password, then with the correct one.
   Sign out and test the updated credentials.
